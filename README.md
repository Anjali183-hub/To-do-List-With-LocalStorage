# To-Do List with Local Storage

A simple To-Do List web application built using HTML, CSS, and JavaScript.

## Features

- Add tasks
- Edit tasks
- Delete tasks
- Add tasks using Enter key
- Light/Dark theme
- Save tasks in Local Storage
- Tasks remain saved after refreshing the page

## Technologies Used

- HTML5
- CSS3
- JavaScript
- Local Storage

## How to Run

Open `index.html` in your browser and start adding tasks.
